GTD事务管理系统 — 隐私政策

更新日期：2026年5月15日

欢迎使用 GTD事务管理系统（以下简称"本应用"）。本应用是一款基于 GTD（Getting Things Done）理论的个人事务管理工具。我们深知个人信息对您的重要性，并会全力保护您的个人信息安全。本隐私政策将向您说明我们如何收集、使用和保护您的个人信息。

请在使用本应用前仔细阅读本隐私政策。使用本应用即表示您同意本隐私政策的条款。

一、信息收集与使用

1.1 我们收集的信息

本应用不收集任何个人身份信息。具体说明如下：

信息类型是否收集说明
个人身份信息（姓名、身份证号等）否不收集
联系方式（手机号、邮箱等）否不收集
位置信息否不收集
设备信息（IMEI、IMSI等）否不收集
通讯录否不收集
相册/摄像头否不收集
麦克风否不收集
存储空间否不收集
网络状态否不收集
任务数据否数据仅存储于本地设备

1.2 权限说明

权限用途是否可选
android.permission.INTERNET（网络访问）用于加载应用内的功能页面必要权限

该权限仅用于加载本应用自身的 Web 内容，不会用于上传您的个人数据。

1.3 信息使用

由于本应用不收集任何个人信息，因此不存在对个人信息的使用、加工或分析行为。您的所有任务数据均存储在您设备的本地存储中，我们无法访问这些数据。

二、第三方SDK

本应用未集成任何第三方数据收集SDK。

SDK名称提供方收集信息用途
无

本应用使用的 AndroidX 等系统库（如 AppCompat、Lifecycle 等）仅用于应用的基本运行支持，不涉及任何用户数据的收集或传输。

三、数据存储与安全

3.1 数据存储位置

  • 您的所有任务数据均存储在本机设备的 Web Storage 中
  • 数据不会上传至任何云端服务器

3.2 数据安全措施

  • 应用不涉及用户数据的网络传输
  • 应用未开通任何数据上传通道
  • 应用不包含任何分析或追踪代码

3.3 数据删除

删除本应用即可清除所有本地存储的数据。由于数据仅存储在本地，删除应用后数据将无法恢复。

四、未成年人保护

本应用不收集任何用户的个人信息，包括未成年人的信息。如果父母或监护人发现未成年人在未获同意的情况下使用本应用，请通过以下联系方式与我们联系，我们将协助处理相关问题。

五、隐私政策更新

我们可能会不时更新本隐私政策。更新后的隐私政策将在应用内或官方网站公布。重大变更时，我们会通过应用更新通知等方式告知您。建议您定期查阅本隐私政策。
